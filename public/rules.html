Rules & imports

Import bank statements

One file per account. Each filename must contain that account's last four digits — a bank export rarely says which account it came from, so the name is the only link. Anything unmatched is reported, never guessed at.

Learned rules

These run before the categoriser on every import, so a wrong one is silent and repeats. Shortest patterns first — a short pattern is the one most likely to catch more than it should.
